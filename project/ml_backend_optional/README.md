# ML-backend

Дополнительно к ручной разметке можно обучить модель object detection, например YOLO, и подключить её к Label Studio как ML-backend.

Возможный порядок работы:

1. Экспортировать размеченные данные из Label Studio.
2. Преобразовать разметку в формат YOLO.
3. Обучить модель на размеченных изображениях.
4. Подключить обученную модель к Label Studio.
5. Использовать модель для автоматической предразметки новых изображений.

В рамках текущей учебной работы ML-backend является дополнительной частью. Основной результат — выбранный датасет, ручная разметка, инструкция для разметчика и скриншоты процесса.
