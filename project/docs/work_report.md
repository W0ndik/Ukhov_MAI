# Описание выполненной работы

В рамках работы была выполнена подготовка датасета для задачи определения болезней пшеницы на изображениях, полученных с беспилотника. Для разметки использовалась система Label Studio, позволяющая вручную выделять объекты на изображениях и назначать им классы.

Для разметки была выбрана задача object detection. На изображениях выделялись прямоугольные области, соответствующие здоровым участкам пшеницы, признакам жёлтой ржавчины, бурой ржавчины, почве и спорным повреждениям.

Была подготовлена конфигурация Label Studio с набором классов: Healthy wheat, Yellow rust, Brown rust, Bare soil / ground и Unclear / other damage. Такой набор классов позволяет не только определять наличие болезни, но и отделять полезные участки изображения от фона и неоднозначных зон.

В ходе разметки изображения открывались в интерфейсе Label Studio, после чего нужные области выделялись прямоугольными рамками. Для каждой рамки выбирался соответствующий класс. После завершения разметки каждого изображения результат сохранялся кнопкой Submit.

Также была подготовлена инструкция для разметчика, где описаны правила выбора классов, требования к точности рамок и порядок действий при спорных случаях. Инструкция нужна для того, чтобы разные разметчики выполняли работу единообразно.

После завершения ручной разметки результат был экспортирован из Label Studio в формате JSON. Полученный экспорт может быть использован для дальнейшей подготовки обучающей выборки и обучения модели компьютерного зрения.
