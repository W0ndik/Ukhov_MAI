# Описание выполненной работы

В рамках работы была выполнена подготовка датасета для задачи определения признаков жёлтой ржавчины пшеницы на снимках с беспилотника. Для ручной разметки использовалась система Label Studio, которая позволяет выделять области на изображениях и присваивать им нужные классы.

В качестве исходных данных был выбран открытый датасет Yellow rust infestation in wheat. Он содержит RGB-снимки пшеничного поля, полученные с беспилотника DJI. Для учебной разметки была использована часть изображений из датасета.

Для разметки была выбрана постановка object detection. На изображениях выделялись прямоугольные области, соответствующие участкам возможного поражения жёлтой ржавчиной, здоровому посеву, следам техники, почве и спорным зонам.

В Label Studio была подготовлена конфигурация интерфейса разметки со следующими классами:

- Yellow rust area — участок с возможными признаками жёлтой ржавчины;
- Healthy wheat / normal canopy — визуально здоровый участок посева;
- Bare soil / ground — почва, пустой участок или зона без растительности;
- Unclear / shadow / blur — спорная, затенённая, размытая или плохо различимая зона.

В ходе разметки каждое изображение открывалось в интерфейсе Label Studio. После этого на нём выделялись прямоугольные области нужных классов. Для каждого изображения результат сохранялся кнопкой Submit.

Также была подготовлена инструкция для разметчика. В ней описаны используемые классы, правила выделения областей, порядок действий при спорных случаях и требования к качеству разметки. Инструкция нужна для того, чтобы разметка выполнялась единообразно и могла быть использована для дальнейшей подготовки обучающей выборки.

После завершения ручной разметки результат был экспортирован из Label Studio в формате JSON. Полученный экспорт может использоваться для дальнейшей обработки данных, обучения модели object detection или подключения ML-backend для автоматической предразметки новых изображений.
