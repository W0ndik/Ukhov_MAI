# Инструкция для разметчика

## Цель разметки

Необходимо разметить RGB-снимки пшеничного поля, полученные с беспилотника. На изображениях нужно выделять прямоугольными рамками участки поля, относящиеся к одному из классов: зона жёлтой ржавчины, здоровый посев, почва или спорная зона.

Разметка выполняется в Label Studio.

## Классы разметки

### Yellow rust area

Класс используется для участков, где заметны признаки жёлтой ржавчины пшеницы. На снимках с БПЛА такие зоны могут выглядеть как жёлтые, светло-жёлтые, бледные или неравномерно окрашенные участки посева.

Выделять нужно не отдельные листья, а видимую область поля с признаками поражения.

### Healthy wheat / normal canopy

Класс используется для участков нормального здорового посева. Обычно это равномерные зелёные зоны без выраженного пожелтения, пятнистости, проплешин и следов повреждения.

### Bare soil / ground

Класс используется для почвы, технологических колей, пустых участков, дорог, междурядий или зон без растительности.

### Unclear / shadow / blur

Класс используется для спорных зон. Его нужно выбирать, если участок затенён, размыт, пересвечен, плохо различим или невозможно уверенно определить, является ли он здоровым или поражённым.

## Правила разметки

1. Размечать нужно только хорошо видимые участки.
2. Рамка должна охватывать участок одного класса.
3. Не нужно захватывать слишком много лишнего фона.
4. Если на изображении есть несколько отдельных поражённых зон, каждую нужно выделять отдельной рамкой.
5. Если поражённая зона большая и непрерывная, её можно выделить одной большой рамкой.
6. Если участок спорный, лучше поставить класс Unclear / shadow / blur.
7. Слишком мелкие и неразличимые зоны размечать не нужно.
8. После разметки каждого изображения нужно нажать Submit.

## Логика выбора класса

Если участок поля жёлтый или бледный и похож на поражение — Yellow rust area.

Если участок равномерно зелёный — Healthy wheat / normal canopy.

Если видна земля, колея или пустой фон — Bare soil / ground.

Если участок плохо виден или непонятен — Unclear / shadow / blur.

## Требования к качеству

Разметка должна быть единообразной на всех изображениях. Похожие участки на разных снимках должны получать одинаковый класс. Рамки должны быть достаточно точными, чтобы полученные данные можно было использовать для обучения модели компьютерного зрения.
