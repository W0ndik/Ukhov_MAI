# Выбор датасета

Для выполнения работы был выбран открытый датасет Yellow rust infestation in wheat, размещённый на платформе Figshare. Датасет содержит RGB-изображения пшеничного поля, полученные с беспилотника DJI, и относится к задаче выявления жёлтой ржавчины пшеницы по снимкам с БПЛА.

Для учебной разметки была использована часть датасета — 15–30 изображений. Изображения были загружены в Label Studio и размечены вручную прямоугольными рамками.

В рамках проекта использовалась следующая схема классов:

- Yellow rust area — участок с признаками жёлтой ржавчины;
- Healthy wheat / normal canopy — визуально здоровый участок посева;
- Bare soil / ground — почва, технологическая колея или участок без растительности;
- Unclear / shadow / blur — спорный, затенённый или размытый участок.

Такой набор классов выбран потому, что снимки сделаны с беспилотника и показывают не отдельный лист, а участок поля. Поэтому разметка выполняется не по отдельным листьям, а по видимым зонам посева.
