# Определение болезней пшеницы на снимках с беспилотника

Проект посвящён подготовке датасета для задачи определения болезней пшеницы на изображениях, полученных с беспилотника.

## Цель работы

Цель работы — выбрать датасет, выполнить ручную разметку части изображений в Label Studio и подготовить инструкцию для разметчика.

## Используемые инструменты

- Label Studio;
- Python;
- изображения пшеницы из открытого датасета;
- ручная разметка прямоугольными рамками.

## Классы разметки

- Healthy wheat — здоровая пшеница;
- Yellow rust — жёлтая / полосатая ржавчина;
- Brown rust — бурая ржавчина;
- Bare soil / ground — почва или фон;
- Unclear / other damage — спорный участок или другое повреждение.

## Структура проекта

```text
data/images/              изображения для разметки
data/exports/             экспорт разметки из Label Studio
label_studio/             конфигурация интерфейса разметки
docs/                     описание датасета, инструкция и отчёт
screenshots/              скриншоты процесса разметки
ml_backend_optional/      дополнительное описание ML-backend
```

## Порядок работы

1. Подобрать и скачать изображения пшеницы.
2. Создать проект в Label Studio.
3. Загрузить XML-конфигурацию разметки.
4. Импортировать изображения.
5. Разметить изображения прямоугольными областями.
6. Сделать скриншоты процесса.
7. Экспортировать результат разметки.
8. Описать выполненную работу в отчёте.
